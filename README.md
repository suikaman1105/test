# IP Messenger (with Supervisor Approval)

同一LAN内のPC間で動作するシンプルなIPメッセンジャー。
ファイル送信は **上長承認フロー** を経由します。

## 機能

- UDPブロードキャストによるユーザー自動検出 (port 2425)
- TCPによるテキストメッセージ送受信 (port 2426)
- ファイル送信ワークフロー:
  1. 送信者が宛先と上長を選び、コメントを添えてファイルをドロップ
  2. ファイルは **上長** に届く (宛先ではなく)
  3. 上長が「承認待ち」タブで内容をプレビューし、**承認** または **否認**
  4. 承認 → 宛先へ転送 / 否認 → 送信者へ通知 (理由付き)
- ファイルアップロード: ドラッグ&ドロップ (`tkinterdnd2`)
- ファイルダウンロード: 受信ファイルは `~/Downloads/ipmsg/` に保存され、
  「受信ファイル」タブから保存先を開けます

## セットアップ

```bash
pip install -r requirements.txt
```

(`tkinterdnd2` が無くてもD&D以外の機能は動作します)

## 起動

```bash
python ipmsg.py [表示名]
```

例: `python ipmsg.py alice`

## 使い方

1. 同じLAN上で複数PCで起動するとお互いに自動検出される
2. **メッセージ/送信** タブで宛先を選択 → メッセージ送信またはファイルD&D
3. ファイルD&D時に上長を選択 + コメント入力 → 上長へ申請
4. 上長は **承認待ち** タブで「プレビュー」で中身確認 → 「承認」または「否認」
5. 受信側は **受信ファイル** タブで保存済みファイルを確認

## ポート

- UDP 2425 (検出)
- TCP 2426 (メッセージ・ファイル)

ファイアウォールでこれらのポートを開放してください。
