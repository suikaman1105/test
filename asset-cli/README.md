# 資産管理 × 40歳1億円ロードマップ CLI

楽天証券・マネーフォワードからコピーしたデータを読み込み、40歳までに1億円を達成するための
ロードマップとアドバイスをターミナルに表示する Python CLI ツールです。

**追加インストール不要**（Python 3.7+ の標準ライブラリのみで動作）。グラフはターミナル内に
カラーのテキストチャートで描画します。

## 使い方

### 1. 対話モード（一番簡単）

```bash
python3 asset_roadmap.py
```

年齢・投資額などを順番に入力し、最後にマネーフォワード／楽天証券のデータを貼り付けます
（貼り付け後、空行で Enter を押すと次へ進みます）。

### 2. データファイルを指定

```bash
python3 asset_roadmap.py \
    --mf sample_mf.txt \
    --rakuten sample_rakuten.txt \
    --age 32 --monthly 100000 --return 5
```

### 3. 総資産を直接指定（万円単位）

```bash
python3 asset_roadmap.py --assets 500 --age 32 --monthly 100000 --return 5
```

## オプション

| オプション | 説明 |
|-----------|------|
| `--mf FILE` | マネーフォワードのデータファイル |
| `--rakuten FILE` | 楽天証券のデータファイル |
| `--age N` | 現在の年齢 |
| `--monthly N` | 月間投資額（円） |
| `--return N` | 想定年間利回り（%） |
| `--assets N` | 現在の総資産（万円）※データ貼付時は不要 |

## データの準備

`sample_mf.txt` / `sample_rakuten.txt` がサンプルです。マネーフォワードや楽天証券の
画面からコピーしたテキストをそのまま貼り付けて使えます。総資産・収入・支出・評価額合計・
損益合計・保有銘柄を自動で読み取ります。

## 出力内容

- 現状サマリー（総資産・達成率・達成予測年齢・含み損益）
- 資産推移シミュレーション（テキストグラフ）
- マイルストーン（年齢別チェックポイント）
- 個別アドバイス（NISA・iDeCo・利回り改善など）
- 保有資産一覧

※ シミュレーションは複利計算による試算です。実際の市場は変動します。
